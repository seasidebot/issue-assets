# issue-assets

GitHub issue / PR 配图的公共存放处（`seasidebot` 账号）。

放在这里的文件必须能被匿名访问 —— GitHub 渲染 issue 里的图片是走 camo 代理匿名抓取的，私有仓库的链接会显示为裂图。
因此**不要往这里放任何含敏感信息的文件**；只放"本来就要公开发布"的配图。

约定路径：`<owner>/<issue-number>/<name>.<ext>`，例如 `rikkahub/1965/deepseek-image-search.png`。

引用方式（raw 链接在 issue/PR 里可直接渲染）：

```markdown
![说明](https://raw.githubusercontent.com/seasidebot/issue-assets/main/rikkahub/1965/deepseek-image-search.png)
```
